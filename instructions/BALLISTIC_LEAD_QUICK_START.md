# Швидкий старт: Балістичне упередження

## 🎯 Що нового

Додано систему візуалізації балістичного упередження - жовте коло на відеопотоці, яке показує куди потрібно прицілюватися з урахуванням балістичних поправок.

## 📁 Створені файли

1. **BallisticConstants.java** - всі константи для балістики
2. **BallisticCalculatorService.java** - інтерфейс сервісу розрахунків
3. **BallisticCalculatorServiceImpl.java** - реалізація розрахунків
4. **BALLISTIC_INTEGRATION.md** - детальна документація (в корені проєкту)

## ✏️ Модифіковані файли

1. **GuiServiceImpl.java** - інтегровано BallisticCalculatorService
2. **SwingGuiServiceImpl.java** - додано малювання жовтого кола

## 🚀 Як запустити

```bash
mvn clean compile
mvn spring-boot:run
```

Система автоматично почне відображати:
- ❌ Червоний хрест - поточне прицілювання
- ⭕ Жовте коло - точка упередження

## ⚙️ Налаштування

Відкрийте `src/main/java/vyrib1/project/aaw/data/BallisticConstants.java` та змініть:

```java
// Балістичні поправки
COME_UP_MRAD = 0.87;        // Вертикаль (падіння кулі)
LEAD_MRAD = -67.89;         // Горизонталь (упередження)

// Зовнішній вигляд кола
AIM_CIRCLE_RADIUS = 30;     // Розмір кола (pixels)
AIM_CIRCLE_COLOR = (0, 255, 255);  // Колір BGR (Yellow)
```

## 📖 Детальна документація

Дивіться `BALLISTIC_INTEGRATION.md` в корені проєкту для:
- Пояснення всіх констант
- Математичні формули
- Приклади розрахунків
- Схема архітектури

## 🔄 Поточний режим

**КОНСТАНТИ**: Система використовує фіксовані значення поправок.

**Майбутнє**: Інтеграція з LRF для реальних розрахунків на основі відстані.

## 📊 Візуалізація

```
┌──────────────────────────────┐
│                              │
│         ❌ (Червоний хрест)   │
│            ↓                 │
│         ⭕ (Жовте коло)       │
│                              │
│  Distance: 100m  Angle: 0*   │
└──────────────────────────────┘
```

Червоний хрест = поточна позиція прицілу (керується GPIO кнопками)  
Жовте коло = розрахована точка для влучання з урахуванням балістики
