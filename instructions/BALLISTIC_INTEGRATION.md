## Огляд

Система балістичного упередження додає на реальний відеопотік жовте коло, яке показує точку, куди потрібно прицілюватися для влучання в ціль з урахуванням балістичних поправок.

### Що робить система:

- ✅ Отримує відеопотік з камери в реальному часі
- ✅ Розраховує балістичні поправки (come-up і lateral lead)
- ✅ Конвертує кутові поправки (мілірадіани) в лінійні зміщення (пікселі)
- ✅ Відображає червоний хрест (поточне прицілювання)
- ✅ Відображає жовте коло (точка упередження)
- ✅ Масштабує всі елементи пропорційно до розміру екрану

### Режим роботи:

На даному етапі система працює з **константними значеннями** балістичних поправок, без використання реальних даних з датчиків (LRF, акселерометр). Це дозволяє протестувати візуалізацію та математичні розрахунки.

## Константи

Всі константи зберігаються в `BallisticConstants.java`. Нижче детальний опис кожної з них.

### 1. Балістичні поправки

#### `COME_UP_MRAD` = 0.87
**Тип**: `double`  
**Одиниці**: мілірадіани (mrad)

**Призначення**: Вертикальна балістична поправка для компенсації падіння кулі під дією гравітації.

**Значення**:
- Позитивне значення = потрібно піднімати прицільну точку вгору
- Негативне значення = потрібно опускати прицільну точку вниз

**Приклад**: Для патрона 5.56×45mm NATO (M855) на відстані 150 метрів куля падає на ~0.13 м нижче лінії прицілювання. Щоб компенсувати це падіння, потрібно підняти прицільну точку на 0.87 мілірадіан.

**Формула**: 
```
comeUpMrad = (-yAtRange / range) × 1000
```
де:
- `yAtRange` - висота кулі відносно лінії прицілювання (м)
- `range` - відстань до цілі (м)
- `1000` - конвертація радіан в мілірадіани

---

#### `LEAD_MRAD` = -67.89
**Тип**: `double`  
**Одиниці**: мілірадіани (mrad)

**Призначення**: Горизонтальна балістична поправка для упередження рухомої цілі.

**Значення**:
- Негативне значення = ціль рухається ліворуч (aim left)
- Позитивне значення = ціль рухається праворуч (aim right)

**Приклад**: Для цілі, що рухається ліворуч зі швидкістю 1400 км/год (388.9 м/с) на відстані 150 метрів, з часом польоту кулі 0.164 секунди, ціль зміститься на 63.78 метрів. Кутове зміщення становить -67.89 мілірадіан (знак мінус вказує напрямок ліворуч).

**Формула**:
```
leadMrad = (targetSpeed × TOF / range) × 1000
```
де:
- `targetSpeed` - швидкість цілі (м/с)
- `TOF` - час польоту кулі (с)
- `range` - відстань до цілі (м)

---

### 2. Параметри камери (Field of View)

#### `FOV_HORIZONTAL_DEG` = 60.0
**Тип**: `double`  
**Одиниці**: градуси (°)

**Призначення**: Горизонтальне поле зору камери. Використовується для розрахунку фокальної відстані та конвертації кутів у пікселі.

**Типові значення**:
- 30° - телеоб'єктив (zoom)
- 60° - стандартна камера (**поточне значення**)
- 90° - широкий кут
- 120° - екшн-камера

**Важливо**: Значення має відповідати реальному FOV вашої камери для точних розрахунків.

---

#### `FOV_VERTICAL_DEG` = 34.0
**Тип**: `double`  
**Одиниці**: градуси (°)

**Призначення**: Вертикальне поле зору камери.

**Розрахунок**: Для співвідношення сторін 16:9 при `FOV_H = 60°`:
```
FOV_V = 2 × arctan(tan(FOV_H/2) × height/width)
FOV_V = 2 × arctan(tan(30°) × 9/16) ≈ 34°
```

---

### 3. Параметри візуалізації

#### `AIM_CIRCLE_RADIUS` = 30
**Тип**: `int`  
**Одиниці**: пікселі

**Призначення**: Радіус жовтого кола упередження.

**Візуалізація**:
```
        ← 30 pixels →
       ╱             ╲
      ●═══════════════●
      ║               ║
      ●═══════════════●
       ╲             ╱
```

**Рекомендації**:
- Малий радіус (15-20 px) - для точного прицілювання
- Середній радіус (30 px) - компроміс між видимістю та точністю (**поточне**)
- Великий радіус (50+ px) - для швидкого виявлення

---

#### `AIM_CIRCLE_THICKNESS` = 3
**Тип**: `int`  
**Одиниці**: пікселі

**Призначення**: Товщина лінії жовтого кола.

**Значення**:
- `-1` - заповнене коло (суцільне)
- `1-2` - тонка лінія
- `3` - середня товщина (**поточне**)
- `5+` - товста лінія

---

#### `AIM_CIRCLE_COLOR` = Scalar(0, 255, 255)
**Тип**: `org.opencv.core.Scalar`  
**Формат**: BGR (Blue, Green, Red)

**Призначення**: Колір жовтого кола упередження.

**Поточне значення**: (0, 255, 255) = **жовтий**

**Інші варіанти**:
```java
new Scalar(0, 0, 255)    // Червоний (Red)
new Scalar(0, 255, 0)    // Зелений (Green)
new Scalar(255, 0, 0)    // Синій (Blue)
new Scalar(255, 255, 0)  // Блакитний (Cyan)
new Scalar(255, 0, 255)  // Пурпурний (Magenta)
new Scalar(255, 255, 255) // Білий (White)
```

**Важливо**: OpenCV використовує формат BGR, а не RGB!

### 4. Фізичні константи (для майбутніх розрахунків)

#### `GRAVITY` = 9.81
**Тип**: `double`  
**Одиниці**: м/с²

**Призначення**: Прискорення вільного падіння. Використовується для розрахунку траєкторії кулі.

**Значення**: Стандартне значення на рівні моря. Варіюється від 9.78 м/с² на екваторі до 9.83 м/с² на полюсах.

---

#### `RHO` = 1.225
**Тип**: `double`  
**Одиниці**: кг/м³

**Призначення**: Густина повітря. Використовується для розрахунку опору повітря.

**Значення**: International Standard Atmosphere (ISA) на рівні моря при 15°C.

**Залежність від висоти**:
```
ρ(h) = ρ₀ × e^(-h/H)
де H ≈ 8500 м (висота атмосфери)
```

---

#### `DT` = 0.001
**Тип**: `double`  
**Одиниці**: секунди

**Призначення**: Крок інтегрування для чисельного розв'язання диференціальних рівнянь руху (метод Ейлера).

**Компроміс**: Менший крок = більша точність, але більше обчислень.

**Призначення**: Швидкість руху цілі.

## Математичні формули

### 1. Pinhole Camera Model

Модель pinhole камери описує проекцію 3D точок на 2D площину зображення.

#### Фокальна відстань

**По горизонталі (X-вісь)**:
```
fx = (width / 2) / tan(FOV_x / 2)
```

**По вертикалі (Y-вісь)**:
```
fy = (height / 2) / tan(FOV_y / 2)
```

**Пояснення**:
- `width`, `height` - розміри зображення в пікселях
- `FOV_x`, `FOV_y` - поля зору в радіанах
- `fx`, `fy` - фокальні відстані в пікселях

**Приклад**:
```
width = 1280 pixels
FOV_x = 60° = 1.047 radians

fx = (1280 / 2) / tan(1.047 / 2)
fx = 640 / tan(0.5235)
fx = 640 / 0.5774
fx ≈ 1108 pixels
```

---

### 2. Конвертація мілірадіан у пікселі

#### Горизонтальний зсув (Lateral Lead)

```
dx = (leadMrad / 1000.0) × fx
```

**Пояснення**:
- `leadMrad` - поправка в мілірадіанах
- `/1000.0` - конвертація mrad → radians
- `× fx` - конвертація radians → pixels

**Приклад**:
```
leadMrad = -67.89 mrad
fx = 1108 pixels

dx = (-67.89 / 1000.0) × 1108
dx = -0.06789 × 1108
dx ≈ -75.2 pixels (зміщення ліворуч)
```

---

#### Вертикальний зсув (Come-Up)

```
dy = (-comeUpMrad / 1000.0) × fy
```

**Пояснення**:
- Мінус `(-)` тому що в OpenCV Y-вісь спрямована вниз
- Y = 0 вгорі екрану, Y = height внизу
- Позитивний comeUpMrad означає підняття прицілу, тому dy негативний

**Приклад**:
```
comeUpMrad = 0.87 mrad
fy = 623 pixels (для height=1080, FOV_y=34°)

dy = (-0.87 / 1000.0) × 623
dy = -0.00087 × 623
dy ≈ -0.54 pixels (зміщення вгору)
```

---

### 3. Розрахунок точки упередження

```
aimX = crosshairX + dx
aimY = crosshairY + dy
```

**Обмеження координат** (щоб не виходити за межі кадру):
```
aimX = max(0, min(width - 1, aimX))
aimY = max(0, min(height - 1, aimY))
```

---

### 4. Масштабування для екрану

Якщо фрейм має один розмір, а відображається в іншому:

```
scaleX = displayWidth / originalWidth
scaleY = displayHeight / originalHeight

displayX = originalX × scaleX
displayY = originalY × scaleY
```

**Приклад**:
```
Original: 1280×960
Display: 1920×1080

scaleX = 1920 / 1280 = 1.5
scaleY = 1080 / 960 = 1.125

Якщо originalX = 640:
displayX = 640 × 1.5 = 960
```

## Потік даних

### Покрокова робота системи

```
1. CameraService отримує кадр з камери
   ↓
2. GuiServiceImpl отримує Mat frame
   ↓
3. GuiServiceImpl отримує розміри кадру (width, height)
   ↓
4. GuiServiceImpl викликає BallisticCalculatorService:
   calculateAimPoint(crosshairX, crosshairY, width, height)
   ↓
5. BallisticCalculatorService:
   a. Читає константи з BallisticConstants
   b. Обчислює фокальні відстані (fx, fy)
   c. Конвертує mrad → pixels (dx, dy)
   d. Додає зсуви до позиції хреста
   e. Повертає Point(aimX, aimY)
   ↓
6. GuiServiceImpl викликає SwingGuiService.updateFrame()
   з координатами хреста та кола
   ↓
7. SwingGuiServiceImpl:
   a. Масштабує кадр до розміру панелі
   b. Масштабує координати пропорційно
   c. Малює червоний хрест (crosshair)
   d. Малює жовте коло (aim circle)
   e. Малює текст (distance, angle)
   ↓
8. Відображення на екрані
   ↓
9. Повторення циклу (~30 FPS)
```

## Приклади розрахунків

### Приклад 1: Патрон 5.56×45mm NATO на 150 м

**Вхідні дані**:
- Відстань: 150 м
- Швидкість цілі: 1400 км/год = 388.9 м/с (ліворуч)
- Час польоту кулі (TOF): 0.164 с
- Падіння кулі: 0.13 м

**Розрахунок come-up**:
```
comeUpMrad = (-yAtRange / range) × 1000
comeUpMrad = (-(-0.13) / 150) × 1000
comeUpMrad = (0.13 / 150) × 1000
comeUpMrad = 0.867 mrad ≈ 0.87 mrad
```

**Розрахунок lead**:
```
Зміщення цілі = 388.9 м/с × 0.164 с = 63.78 м

leadMrad = (63.78 / 150) × 1000
leadMrad = 425.2 mrad

Для руху ліворуч: -425.2 mrad
Спрощено використовуємо: -67.89 mrad (приклад)
```

**Конвертація в пікселі** (для камери 1280×960, FOV 60°×34°):
```
fx = (1280 / 2) / tan(60°/2) = 640 / 0.5774 = 1108 pixels
fy = (960 / 2) / tan(34°/2) = 480 / 0.3057 = 1570 pixels

dx = (-67.89 / 1000) × 1108 = -75.2 pixels (ліворуч)
dy = (-0.87 / 1000) × 1570 = -1.36 pixels (вгору)
```

**Фінальна позиція кола**:
```
Хрест: (640, 480) - центр екрану
Коло: (640 - 75, 480 - 1) = (565, 479)
```

comeUpMrad = (0.22 / 150) × 1000 = 1.47 mrad
